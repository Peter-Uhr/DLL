### For steps on how to debug and use Edit and Continue in Visual Studio without restarting AutoCAD:
> Open your project in Visual Studio.\
> Go to Tools > Options > Debugging > General.\
> Ensure Enable Edit and Continue is checked.\
> Set up your debugging profile to launch AutoCAD automatically (acad.exe) when you hit "Start".\
> When you modify your code, click the Hot Reload button or apply code changes while the debugger is attached.
